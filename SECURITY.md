# Security

Everything in this toolkit — the setup script, the `clbs`/`clbs-run` launchers,
the SessionStart hook, and the statusline — runs on users' machines, and the
brainstorm window runs with permission prompts disabled.

If you find a vulnerability, please report it privately via GitHub's
**Report a vulnerability** button (Security tab of this repository) instead of
opening a public issue. Fixes ship as new plugin versions.
