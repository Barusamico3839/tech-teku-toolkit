# Harnesseed P3 "harness-checkup" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `/harnesseed:checkup` — a read-only health check of the user's real harness environment against the awesome-harness-engineering ~12-category taxonomy, reporting present/partial/absent per category with evidence and a ranked gap list, saved into the seedling.

**Architecture:** Spec §8. A deterministic collector (`collect.py`) gathers the machine-readable facts (settings.json keys, plugins, marketplaces, MCP files, CLAUDE.md presence, skills) into JSON; the skill feeds those facts plus targeted file reads through the canon checklist (`blueprint/checkup-checklist.md`, read from roots/) and writes the report to `checkups/YYYY-MM-DD-checkup.md` (one seedling commit). Checkup never modifies anything — changes flow only through P4 grow (or user hands).

**Tech Stack:** Python 3 stdlib collector, bash tests, SKILL.md.

### Task 2: Collector (skills/checkup/collect.py) — TDD

**Files:**
- Create: `plugins/harnesseed/skills/checkup/collect.py`
- Create: `tests/checkup-collect-tests.sh`

**Interfaces:**
- Produces: `python3 collect.py <config-dir> [project-dir]` → JSON to stdout:
  `{"settings": {"exists": bool, "parse_ok": bool, "permission_rules": {"allow": n, "deny": n, "ask": n}, "enabled_plugins": n, "disabled_plugins": n, "hooks_events": [names], "output_style": str|null, "model": str|null}, "plugins": {"installed": n, "marketplaces": [names]}, "mcp": {"user_file": bool, "project_file": bool}, "claude_md": {"global": bool, "project": bool}, "skills_dirs": n, "workflows": {"dir_exists": bool}}`
  — key names/counts/booleans only, never values. Missing files → exists:false, no crash.
- Consumed by: checkup SKILL.md step 1.

Tests (fixture dirs in mktemp): full fixture → all fields correct; empty config dir → everything false/0, exit 0; broken settings.json → parse_ok:false, exit 0.

### Task 3: `/harnesseed:checkup` skill (SKILL.md)

**Files:**
- Create: `plugins/harnesseed/skills/checkup/SKILL.md`
